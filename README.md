## Tema do Trabalho
**Gestão de Stocks e Vendas em E-Commerce**
O objetivo deste trabalho é demonstrar a integração e transformação de dados de e-commerce utilizando duas plataformas ETL distintas (Pentaho Data Integration e KNIME).

## Estrutura do Repositório
* `/data`: Ficheiros de dados de entrada (CSV, JSON, XML).
* `/pentaho`: Transformações (.ktr) e Jobs (.kjb) em Pentaho Kettle.
* `/knime`: Workflows em KNIME (.knwf).
* `/sql`: Scripts SQL de base de dados.
* `/docs`: Relatório final e documentação do projeto.
